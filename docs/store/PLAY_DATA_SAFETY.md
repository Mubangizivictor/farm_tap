# Google Play: Data safety answers

Play Console > App content > Data safety. Answer exactly as below.

**Does your app collect or share any of the required user data types?** Yes
**Is all of the user data collected by your app encrypted in transit?** Yes
**Do you provide a way for users to request that their data is deleted?** Yes,
in the app (Settings > Delete my account) and on the web:
https://farmtap.victorbee.com/delete-account/
(Closed accounts are kept 90 days so support can restore them, then erased.)

**Shared with third parties:** No data is shared for advertising or sold.
Payment details go to the payment provider the user chooses (MTN, Airtel,
Flutterwave) only to process that payment; Play treats this as a service
provider, so answer "not shared".

| Data type | Collected | Optional | Purpose |
| --- | --- | --- | --- |
| Personal info: Name | Yes | No | App functionality, Account management |
| Personal info: Email address | Yes | No (owners) | Account management |
| Personal info: Phone number | Yes | Yes | App functionality (worker sign-in, Mobile Money, reminders) |
| Personal info: Address (district/village of the farm) | Yes | Yes | App functionality |
| Financial info: Purchase history (FarmTap plan payments) | Yes | No | App functionality |
| Financial info: Other (farm sales, spending, wages the user records) | Yes | Yes | App functionality |
| Location: Approximate location | Yes | Yes | App functionality (fills the farm's district once) |
| Photos and videos: Photos | Yes | Yes | App functionality (profile, worker and animal photos, receipts) |
| App activity: App interactions | Yes | No | Analytics |
| App info and performance: Crash logs, Diagnostics | Yes | No | App functionality |
| Device or other IDs | Yes | No | App functionality (push notifications token, device id on records) |

Not collected: precise location, contacts, messages, calendar, health and
fitness, audio, files, web browsing, race/religion/politics.

**Ephemeral processing:** No. **Collection required for the app to work:** as marked.
